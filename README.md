# JPLE Technicien

Site HTML/CSS/JS + Supabase : inscription, connexion, mot de passe oublié, session persistante, tableau de bord personnel.

## Mise en ligne
1. Supabase > SQL Editor : exécuter `schema.sql`.
2. Supabase > Authentication > URL Configuration :
   - Site URL : `https://johnpeteravoce-lang.github.io/jpletechnicien/`
   - Redirect URLs : ajouter `https://johnpeteravoce-lang.github.io/jpletechnicien/**`
3. Envoyer tous les fichiers à la racine du dépôt GitHub, puis Settings > Pages > branche `main`, dossier `/ (root)`.
